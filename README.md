# Saray Mebel — Android MVP

Android-приложение на Java: вход через Supabase Auth, просмотр и добавление клиентов, заказов и платежей. Русский, узбекский, туркменский языки. Валюта TMT.

## Сборка без компьютера
1. Создайте **новый пустой** репозиторий GitHub.
2. Загрузите **содержимое** этой папки в корень репозитория (не вкладывайте папку SarayMebel целиком).
3. Откройте **Actions → Build Android APK → Run workflow** или дождитесь сборки после push.
4. Когда появится зелёная галочка, откройте запуск → **Artifacts → SarayMebel-APK**. Скачайте ZIP с `app-debug.apk` и установите APK.

## Важно
- В Supabase Auth должен быть создан пользователь с email и паролем. В приложении нет регистрации.
- Существующие RLS-политики разрешают доступ только тому пользователю, чей UID прописан в политиках. Для работников нужны отдельные учётные записи и безопасные политики доступа.
- **Офлайн-режим ограничен чтением ранее загруженных данных**. Создание/редактирование без интернета и синхронизация не реализованы.
- Это первая тестовая версия: пока нет редактирования/удаления, восстановления сессии через refresh token, и безопасного распределения ролей.
- Публичный Supabase publishable key допустим в клиенте; никогда не помещайте `service_role` или secret key в APK.
